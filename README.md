# Student_FormStudent Form Website

A simple Student Form Website built using HTML, CSS, and JavaScript. This project allows users to enter student details, save them, display them in a table, and delete student records dynamically.

🚀 Features
Add student details.
Enter student name and age.
Select gender (Male/Female).
Choose a course from the dropdown.
Enter student email.
Display student details in a table.
Delete student records.
Simple and user-friendly interface.
Dynamic table updates using JavaScript.
🛠️ Technologies Used
HTML – Structure of the website.
CSS – Styling and layout.
JavaScript – Adding and deleting student records dynamically.
📸 Project Preview

The website contains:

Student registration form.
Student details table.
Save and Delete buttons.

💻 How to Run the Project
Clone this repository:
bash
git clone YOUR_REPOSITORY_URL

Open the project folder.
Open index.html in your browser.
Enter student details in the form.
Click the Save button to add the student.
Click the Delete button to remove a student record.
⚙️ Functionality
Save Student

The saveStudent() JavaScript function collects student details and dynamically adds them to the table.

Delete Student

The deleteStudent() function removes the selected student record from the table.

⚠️ Note

This project uses basic JavaScript without a database. Student records are stored temporarily in the webpage and will be lost when the page is refreshed.
